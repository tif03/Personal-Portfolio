# Tiffany Yu Personal Portfolio

My personal portfolio website, built from scratch.

## Tech Stack

**Frontend:** React, TypeScript, Vite, Tailwind CSS

**Backend:** Node.js, Express, SQLite

**Integrations:** GitHub API, Nodemailer, Resend

**Deploy:** Vercel (frontend) · Railway (backend)

## Features

- GitHub API integration: live pull of public repos
- Contact form with backend validation and database storage
- Dance section with YouTube carousel and filter
- Scrapbook-inspired UI with custom assets
- Docker containerized backend
